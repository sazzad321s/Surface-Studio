Project Name: Surface Studio  Peer-to-Peer Creative Workspace & Production Studio Sharing Platform

Description: This is a platrform where anyone can list his studio hourly based payment.And a user can rent a studio as of their choice with a secure payment booking.This is one platform where you can find different types of studio.

Feature: 
1. Mobile responsive
2. Secure Booking System.
3. List your own space.
4. Directly connected to host and client.
5. No Duplicate booking time.
6. No double payment hassle.
